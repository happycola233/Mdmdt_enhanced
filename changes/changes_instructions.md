# 修改说明

## 高亮与选区颜色的调整（`mdmdt.css`，`mdmdt-light.css`，`mdmdt-dark.css`）
- 搜索命中、鼠标拖拽选中文本、编辑器中的选区高亮，现在全部统一成一套紫色（新增变量 `--color-4-0-c` 控制透明度）。这样无论是查找结果还是 CodeMirror 中的选区，都会呈现一致的紫色色块，符合“用 color-4 系列紫色”的要求。
- `<mark>` 标签（Typora 中的高亮文本）背景换成要求的淡黄色 `rgba(255, 236, 153, 0.85)`。同时按主题切换文字颜色，保证浅色主题下文字仍是深色，深色主题下文字会变成背景色那样的深色，避免黄色底上的白字看不清。
- 如果高亮内容里还有行内代码（比如 <code>\=\= `code` \=\=</code>），我们去掉原本的深蓝底色，让代码文字直接跟随高亮色显示，从而避免深色主题下黄底 + 蓝底叠加导致的对比度问题。

## 浅色模式代码块背景统一（`mdmdt.css`，`mdmdt-light.css`，`mdmdt-dark.css`）
- 多行代码块（Typora 后台对应 `pre` 元素）在浅色模式下改成统一的浅灰色背景 `rgb(245, 245, 245)`。这个颜色也同时应用在代码块左侧的行号栏（`.CodeMirror-gutters`），让整块区域看起来是同一个浅灰色，而不是之前的“主区域浅灰 + 行号列旧灰”错配情况。
- 深色模式下仍然引用原本的深色背景，视觉表现保持不变。

## 内联背景的文字颜色修正（`mdmdt.css`，`mdmdt-dark.css`）
- 对所有使用了行内 `style="background: …"` 的 `span` 元素统一设置文字颜色为黑色。这确保用户在深色模式下自己加背景色时，文字不会变浅而看不见，同时和浅色模式默认的文字颜色保持一致。

## 源码视图间距更新（`mdmdt.css`、`mdmdt-light.css`、`mdmdt-dark.css`）

- 移除了 `#typora-source .CodeMirror-lines pre` 的**上下内边距**，仅保留 **16px 的左右内边距**，这样在切换到源码模式时就不会再“撑大”行间距。

## 列表项的左侧间距调整（`mdmdt.css` / `mdmdt-light.css` / `mdmdt-dark.css`）

- 无序列表、任务列表统一为 4px 左内边距，并移除列表项内段落的负 margin，保证列表标记与内容的间距与有序列表一致。
- 导出/无边框模式下同步新增列表项内边距规则，保持不同视图中的缩进一致性。

## 脚注渲染全面优化（`mdmdt.css`、`mdmdt-light.css`、`mdmdt-dark.css`）

- 正文中的脚注引用由裸数字改为方括号包裹的上标（如 `[1]`）。方括号用 `sup.md-footnote` 的伪元素实现，当 Typora 展开原始 `[^1]` 语法时（光标进入、选区展开 `md-expand-on-selection`、搜索命中 `md-search-expand` 等）自动隐藏，避免出现 `[[^1]]` 双括号的回归问题。
- 编辑器中的脚注定义行不再显示原始的 `[^1] :` 标记（此前 `^` 会裸露显示且间距怪异），改为有序列表风格的 `1.` 序号：去掉 `[^` 伪元素、`] :` 改为 `.`，序号左对齐、取消加粗，并为整行加悬挂缩进，折行后与内容对齐。仅作用于 `.md-def-footnote`，引用式链接定义（`[label]: url`）样式保持不变；脚注名为空时保留 Typora 原生的输入占位提示。
- 导出 HTML/PDF 的脚注区域（`.footnotes-area`）同步优化：字号统一为 14px（原默认 0.7em 过小），文字颜色跟随主题正文色（不再是固定灰色 #888），脚注内容中的链接使用主题链接色，并应用与编辑器一致的悬挂缩进。
- 修正导出时脚注引用数字继承全局 16px 链接字号导致偏大的问题（`sup.md-footnote a` 改为继承上标字号）。

## 原始 HTML 向 GitHub 渲染效果对齐（`mdmdt.css`、`mdmdt-light.css`、`mdmdt-dark.css`）

- 原始 HTML 块里的 `<p>` / `<td>` / `<th>` / `<h1>`~`<h6>` 改回 `white-space: normal`。此前主题对 `p`、`td`、`th` 强制了 `pre-wrap`（Typora 基础样式对标题也是 `pre-wrap`），导致 README 中按行书写的徽章、链接在 Typora 里被拆成一行一个、还带着源码缩进；GitHub 会把这些换行和缩进折叠成普通空白。
- Typora 遇到空行就会结束 HTML 块，README 常见的 `<div align="center">` + 空行 + 若干块 + `</div>` 会被拆成兄弟块，居中失效。现在用兄弟选择器识别“只含空 `<div align="center">` / `<center>` 的 HTML 块”（开）与“只含一个原始标签的段落”（闭，如 `</div>`），把两者之间的块按 `text-align: -webkit-center` 居中（与浏览器处理 `align="center"` 的方式一致），代码块、公式块保持左对齐；每篇文档最多支持 4 个这样的区域。区域末尾的 `</div>` 原始标签默认隐藏，光标移入时恢复显示以便编辑。不含空行、自身闭合的 `<div align="center">…</div>` 本来就能正常居中，不受影响。
- 原始 HTML 块里的图片不再被主题强加 `16px` 上外边距和 `8px` 圆角，按作者写法渲染（徽章保持 `flat-square` 直角、内联 `style`/`width` 可生效）；`<section>` 图片网格和 Markdown 图片保持原样。
- 包裹图片的链接（如徽章 `<a><img></a>`、`[![badge](…)](…)`）不再显示主题的链接小图标；纯文字链接的图标保持不变。
- 原始 HTML 表格（未写 `width` 属性时）按内容宽度排版，`<table align="center">` 可以真正居中，与 GitHub 一致。
- 以上仅作用于编辑视图：Typora 导出 HTML/PDF 时原始 HTML 不带任何包裹元素，无法与 Markdown 段落区分，导出效果保持不变。

## 引用与提示块改为 GitHub（GFM）样式（`mdmdt.css`、`mdmdt-light.css`、`mdmdt-dark.css`）

- 普通引用（`>`）：去掉浅蓝背景和圆角，改为 GitHub 的灰色竖线（`0.25em`）+ 弱化文字颜色，内边距 `0 1em`。
- 提示块（`> [!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]`）：去掉彩色背景和圆角，只保留彩色竖线；标题行（图标 + 类型名）使用对应颜色并独占一行，与正文间隔 16px；正文恢复为正文颜色，不再整段染色。
- 配色改用 GitHub 的语义色，并修正此前 WARNING（红）与 CAUTION（橙）对调的问题：NOTE 蓝、TIP 绿、IMPORTANT 紫、WARNING 琥珀、CAUTION 红。浅色 / 深色各一套，新增变量 `--quote-text-color`、`--quote-border-color`、`--alert-{note,tip,important,warning,caution}-color`，`mdmdt.css` 的深色模式随系统切换。
- Typora 编辑器里标题后面紧跟一个软换行（导出时是 `<br>`），标题改为独占一行后将其收起，避免多出空行；`[!NOTE]` 后空一行再写正文时同样保持 16px 间隔。光标进入标题时仍会显示原始的 `[!NOTE]` 标记。

## 链接、标题、图片网格与深色背景向 GitHub 对齐（`mdmdt.css`、`mdmdt-light.css`、`mdmdt-dark.css`）

- 链接：去掉正文链接前的链接小图标和 2px 左内边距；颜色改为 GitHub 链接色（浅色 `#0969da` / 深色 `#4493f8`，新增变量 `--link-color`）；字号、字重跟随上下文（此前全局 `a` 固定 16px，标题里的链接会被缩小）；悬停只加下划线、不再变成橙色。仅作用于正文（`:where(#write) a`），Typora 界面里的链接样式不变，脚注、目录等专门样式仍然优先。
- 标题：显式设置 GitHub 的字重 600（微软雅黑下显示为粗体），并去掉标题额外的 2px 字距，使标题与 GitHub 一样紧凑醒目。
- 段落换行：开启 Typora「忽略连续的空格与单个换行」（编辑 → 空格与换行 → 取消「保留单换行符」）后，段落内的单个换行按 GitHub 规则显示为空格，README 里逐行书写的 Markdown 徽章会排成一行。此前 `mdmdt.css` 对 `p` 强制 `pre-wrap !important`，会让这个选项失效。
- `<section>` 图片网格：悬停时改用外扩阴影绘制背景面板，不再增加 16px 内边距，图片尺寸保持不变（此前悬停会让网格可用宽度变小、图片整体缩小）。
- 深色背景加深（保持原来的中性灰黑色调，不采用 GitHub 偏蓝的深色）：`--bg-color` `#1b1b1f` → `#121214`，`--bg-color2` `rgb(40, 42, 50)` → `#1f2026`（代码块、表格斑马纹、悬停背景等随之变深）；文件菜单面板的深色背景同步更新。

## 正文字距、表格、图片与分隔线间距微调（`mdmdt.css`、`mdmdt-light.css`、`mdmdt-dark.css`）

- 正文字距：Windows 由 `1px`、其他平台由 `0.6px` 统一改为 `0.8px`（GitHub 为 0，中文完全不加略显拥挤）。
- 表格：单元格内边距 `10px` → `8px 12px`，行高 1.6 → 1.5，每行高度约 46px → 40px（GitHub 约 37px）；整行宽、圆角、斑马纹等主题特色保持不变。
- 图片：去掉图片与外层 `span.md-image` 各自叠加的 `16px` 上外边距；只含一张图片的段落里图片顶对齐，并沿用普通段落的外边距。图片与上下文字的距离由约 51px / 31px 变为 19px / 19px，与两段文字之间的距离一致；图片和文字混排（如行内徽章）不受影响。圆角保持 `8px`，与表格、代码块一致。
- 分隔线：上下外边距固定为 `24px`，并把分隔线前一个段落的 `-5px` 下外边距归零，分隔线与上下文字的距离由约 3px / 16px 变为 24px / 24px，与 GitHub 一样居中；线条保持 1px 细线。
- 表格四角边线：缩放较低时 1px 的圆角弧线只有约一个屏幕像素宽、以半透明方式绘制，表头与斑马纹的单元格背景沿同一条弧线裁剪并画在边框之上，四个角的边线几乎看不见（放大到 170% 左右才恢复）。正文表格的外框改用 `outline`（`outline-offset: -1px`）绘制：outline 在子元素之后绘制，不会被单元格背景覆盖，同样跟随 8px 圆角；同时去掉外层 `figure` 的圆角，避免它沿同一弧线裁剪（Typora 给 `figure` 设了 `overflow-x: auto`）。
